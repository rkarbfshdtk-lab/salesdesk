SALES DESK v6.6 GITHUB UPDATE GUIDE

1) GitHub 로그인 -> salesdesk 저장소 열기
2) 저장소 상단 Add file -> Upload files
3) 이 ZIP을 압축 푼 뒤, 안의 파일/폴더 전체를 업로드
   - index.html
   - api/
   - package.json
   - vercel.json
   - 기타 안내/SQL 파일
4) 같은 이름의 기존 파일이 있으면 새 파일로 교체
5) 아래 Commit changes 클릭
   Commit message 예: Update SALES DESK v6.6
6) Vercel은 GitHub main 브랜치 연결 상태라면 자동 배포
7) Vercel -> salesdesk11 -> Deployments에서 Ready 확인
8) 테스트
   https://salesdesk11.vercel.app/api/health
   https://salesdesk11.vercel.app/api/foodsafety?mode=material&keyword=낙지
   https://salesdesk11.vercel.app/api/franchise?rows=30
